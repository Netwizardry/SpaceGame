# UI/UX 인터페이스 명세 (Visual & Interaction)

## 1. 비주얼 컨셉
- **스타일:** 2D DOS VGA (640x480) 스타일.
- **색상:** ANSI 16색 기반, 고대비 텍스트 위주.
- **애셋:** 도트 아트 함선 아이콘 + AI 생성 인물 초상화.

## 2. 화면 계층 구조 (Layout Layers)
1.  **전역 오버레이 (Global):** 상단 날짜(우주력), 현재 자금(Jaggle), 알림 센터.
2.  **메인 뷰포트 (Main View):**
    - **전략 모드:** 은하계 노드 맵 (성계 간 간선 표시).
    - **전술 모드:** 2D 전술 그리드 및 개별 유닛 유닛 배치.
3.  **윈도우 시스템 (Windowing):**
    - 함선 피팅창, 행성 인프라 창, 캐릭터 프로필 창 등이 겹칠 수 있는 'Floating Window' 방식.

## 3. 조작계 (Controls)
- **마우스:** 우클릭(정보 확인), 좌클릭(선택/이동), 드래그(범위 지정).
- **단축키:**
    - `S`: 전략 모드 전환
    - `T`: 전술 턴 실행
    - `P`: [제안] 메뉴 호출
    - `Esc`: 모든 활성 윈도우 닫기

## 4. HUD (Heads-Up Display)
- **살보 미터:** 교전 시 예측 손실률과 방어막 상쇄 기대값을 막대 그래프로 실시간 표시.
- **적극성 게이지:** 캐릭터 성향에 따라 실시간으로 변동되는 적극성 수치 시각화.
