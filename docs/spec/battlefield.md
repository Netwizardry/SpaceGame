# 전장 설계 및 그리드 (Battlefield & Grid Data)

## 1. 전술 좌표계 (Tactical Grid)
- **규격:** 100 x 100 사각 그리드 (Square Grid).
- **해상도:** 1 Grid = 1,000km.
- **배치:** 공격측(Top 20%), 방어측(Bottom 20%). 중앙은 중립 교전 지역.

## 2. 지형지물 효과 (Terrain Effects)
| 지형 타입 | 이동 비용 | 명중률 보정 | 특수 효과 |
| :--- | :--- | :--- | :--- |
| **공간 (Empty)** | 1.0 | 0% | 표준 공간 |
| **성운 (Nebula)** | 1.5 | -25% | 레이더 탐지 불가 (Stealth 상시 적용) |
| **소행성대 (Asteroid)** | 2.0 | -10% | 턴 종료 시 일정 확률로 Structure 데미지 |
| **블랙홀 (Black Hole)** | 불가 | - | 반경 5 Grid 이내 진입 시 매 턴 중앙으로 견인 |
| **우주조류 (Space Current)** | 0.5 ~ 2.0 | - | 특정 방향 이동 시 속도 가속/감속 |

## 3. 전장의 안개 (Fog of War)
- **탐지 범위:** 함대 내 최고 [정보(INF)] 수치에 비례.
- **식별 단계:**
    1.  **불명 (Unknown):** 존재만 확인 (점/노이즈).
    2.  **포착 (Detected):** 함종(Class)만 확인.
    3.  **식별 (Identified):** 세부 스펙 및 지휘관 정보 확인.
