# 천문 및 행성 데이터 (Astronomy & Planet Data)

## 1. 행성 광물 밀도 (Mineral Richness)
행성의 산업 산출량은 광물 밀도 계수(K_min)에 의해 최종 결정됨.
- **Ultra-Poor:** K_min = 0.2
- **Poor:** K_min = 0.5
- **Abundant:** K_min = 1.0 (기준)
- **Rich:** K_min = 2.0
- **Ultra-Rich:** K_min = 5.0

## 2. 행성 타입 및 기후 패널티 (Climate & Maintenance)
각 행성은 기후(Climate)에 따라 시설 유지비(Maint_Cost)와 산출량에 추가 계수를 가짐.
| 타입 | 유지비 할증 | 식량 산출 | 비고 |
| :--- | :--- | :--- | :--- |
| **Toxic** | +50% | 0.0 | 테라포밍 불가 |
| **Radiated** | +25% | 0.0 | 보호막 선행 필요 |
| **Barren** | 0% | 0.0 | 연구 특화 권장 |
| **Ocean/Swamp** | 0% | 1.5 | 농업 특화 |
| **Terran** | 0% | 2.0 | 최적 환경 |
| **Gaia** | 0% | 3.0 | 최대 인구수 보너스 |

## 3. 중력 계수 (Gravity Constraints)
- **저중력 (Low-G):** 과학/농업/노동 산출 -25%.
- **정상 중력 (Normal):** 0%.
- **고중력 (High-G):** 과학/농업/노동 산출 -50%. (보행 장비 기술로 상쇄 가능).

## 3. 천문 현상과 전술
- **성운 (Nebula):** 함대 레이더 탐지력 무력화. 은영전식 매복 전술 가능.
- **슬링샷 항법:** 거대 항성이나 블랙홀 근처 이동 시 연료 절약 및 가속 효과.
